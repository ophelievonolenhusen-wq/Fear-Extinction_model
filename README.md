# Fear & Extinction model - Mean field and Spiking Neuron Network
Reproducing https://pubmed.ncbi.nlm.nih.gov/21437238/ for a Biophysical Modelling course. The code files are taken from https://github.com/tawantayron/RE-Fear-and-extinction-in-a-BA-net-model (Carvalho, T.T.A., Domingos, L.B., Shimoura, R.O., et al. 2021. [Re] Context-Dependent Encoding of Fear and Extinction Memories in a Large-Scale Network Model of the Basal Amygdala. ReScience C 7, 1, #9.)

This repository is used for running the code from the replication of Carvalho et al. (2021) in Google Colab, using this notebook: https://colab.research.google.com/drive/1Wrs9o5ZNDpRYkC1JSdha2xiJniFSv8hP?usp=sharing

The notebook aims to provide an environment in which it is possible to change the parameters and variables of both the mean-field and the spiking neuron network model in order to see how the behaviour of the models change in response, so as to gain general understanding of these types of models.
